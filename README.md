# Trivia-Game

Trivia-Game is a command-line trivia application that allows players to choose a topic, answer questions, receive immediate feedback, and keep track of their score.

## Features

- Choose from Coding, Capitals, Space, Geography, and Entertainment topics
- Choose All Topics for a mix of trivia questions
- Questions are randomized for each game
- Answer questions using an interactive command-line menu
- Receive immediate correct or incorrect feedback
- Each question has a 3-second time limit
- View your final score at the end of the game
- Play again, return to the main menu, or quit

## Installation

Clone the repository and install the dependencies:

```bash
npm install
```

## Running the Game

Run the game with:

```bash
node bin/index.js
```

## How to Play

1. Select **Start Game** from the main menu.
2. Choose a trivia topic.
3. Select an answer before the timer runs out.
4. Receive immediate feedback after each question.
5. View your score when the game ends.
6. Choose to play again, return to the main menu, or quit.
